# High-Cloud-Airlines-Dashboard

📊 Project Overview
This project focuses on analyzing airline performance and passenger trends using an interactive Power BI dashboard. The goal is to extract meaningful insights related to load factor, routes, airline efficiency, and travel patterns.

🎯 Objectives
Analyze passenger traffic across different airlines and routes
Evaluate load factor (seat utilization efficiency)
Identify trends over time (year-wise performance)
Compare weekday vs weekend travel patterns
Understand distribution of flights based on distance groups

📌 Key Insights
Total Passengers: 187M+ across multiple airlines
Average Load Factor: 77%
Some airlines achieve up to 95% load factor, indicating high efficiency
Load factor shows a steady increasing trend over the years
Weekday and weekend traffic is almost equally distributed
Mid-range flights (500–999 miles) have the highest number of flights

🛠 Tools & Technologies
Power BI
Data Cleaning & Transformation
Data Visualization
KPI Design

📂 Dashboard Features
KPI cards for quick insights
Airline-wise and route-wise analysis
Year-wise trend visualization
Distance group segmentation
Interactive filters (Source, Destination, Year)
